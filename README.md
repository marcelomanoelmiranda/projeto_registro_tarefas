# 📌 Projeto Sistema de Agendamento de Tarefas
Este simples programa busca permitir consultar, criar, alterar e remover as tarefas e agendamentos diveros realizados no sistema.

## 🚀 Tecnologias Utilizadas
- [FastAPI](https://fastapi.tiangolo.com/)
- Python 3.11
- Uvicorn

## 📦 Instalação
Para rodar o projeto localmente, siga os passos:

#Execute o script SQL no SQL Server Management Studio

```sh
# Clone o repositório
git clone https://github.com/marcelomanoelmiranda/projeto_registro_tarefas

# Entre na pasta do projeto
cd seu-repositorio

# Instale as dependências
pip install -r requirements.txt

# Execute o servidor
uvicorn main:app --reload
